# Data access analysis
Existing source: public properties get/list through REST; immutable snapshot fallback. Existing authorization: users/{email} admin/host with primary-host fallback. New client performs onSnapshot/get and transaction create/update at stock_map_highlights/{64-hex hash}; no list/delete query. Public fields: normalized project, houseNumber, text, mode, revision, updatedAt. All new writes require verified email plus the existing role. No rules outside this new match are changed. Validation and unauthorized writes were tested with Firebase emulator. The baseline was downloaded from active release 157b133f-e6fe-4e45-8517-e02258703504 before editing.
